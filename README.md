# YiwuMarketConnect

Eric's personal sourcing agent website for small businesses worldwide.

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS
- Three.js (Fermat spiral hero animation)
- Google Apps Script (form backend)

## Quick Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
